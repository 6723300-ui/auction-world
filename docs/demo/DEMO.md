# Auction World 시연 자료

## 제공 자료

- `auction-world-overview.mp4`: 실제 화면 캡처를 순서대로 보여주는 약 52초 소개 영상. 1920×1080, 무음 자막.
- `../images/`: 검색, 구매 팝업, 보관함, 판매 등록, 거래 완료 화면과 소개 표지.

소개 영상은 연속 조작 녹화가 아닙니다. 캡처를 위해 거래를 새로 생성하거나 기존 DB의 아이템·잔액을 변경하지 않았습니다. 판매 이미지는 입력만 완료한 등록 전 화면이며, 완료 이미지는 이미 대금을 받은 거래를 보여줍니다.

## 직접 거래를 시연하는 순서

프로젝트 루트에서 서버를 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m uvicorn main:app --reload
```

브라우저에서 `http://127.0.0.1:8000/market`을 엽니다. 데모 계정 준비 방법은 프로젝트 README와 `seed_demo.py`를 참고합니다. 기존 계정이 있으면 seed 스크립트는 비밀번호·잔액·아이템을 초기화하지 않습니다.

1. `demo_seller`로 로그인하고 보관함에서 모험가의 검을 선택합니다.
2. 분류는 무기, 개당 가격은 1,000, 판매 수량은 2로 등록합니다.
3. `demo_buyer`로 로그인하고 등록한 상품을 검색합니다.
4. 상품을 더블클릭해 수량 1개, 총액 1,000을 확인하고 구매합니다.
5. 완료 탭의 구매 내역에서 물품을 수령합니다. 보관함에 검이 1개 추가되는지 확인합니다.
6. 판매자로 다시 로그인합니다. 완료 탭의 판매 내역에서 해당 거래의 판매 대금을 수령합니다.
7. 판매자의 재화가 1,000 증가하고 처리 상태가 대금 수령 완료로 바뀌는지 확인합니다.
8. 판매 탭에서 남은 수량 1개를 취소하고, 보관함에 검 1개가 반환되는지 확인합니다.

처음 생성한 데모 계정 기준으로 구매자는 재화 999,000과 검 1개, 판매자는 재화 1,000과 검 4개가 됩니다. 기존 계정으로 시연했다면 시작 시점 잔액과 수량을 기준으로 증감을 확인합니다. 구매 직후 판매자의 재화는 아직 증가하지 않으며 대금 수령 시 증가합니다.
